<h1 align="center">RC-Coupling-Beam-GUI</h1>

<h3 align="center">
  Interpretable Machine-Learning Tool for Predicting Ultimate Shear Capacity of RC Coupling Beams
</h3>

<p align="center">
  A lightweight GUI and Python API that loads pretrained models (XGBoost, CatBoost, LightGBM, PS, MLP, Random Forest) and
  estimates the ultimate shear capacity of RC coupling beams by providing relevant input features.
</p>
